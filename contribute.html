Contribute to EQQN

Learn how to submit new predictions, update past data, and publish earthquake news.

The GitHub Pull Request Workflow

To ensure absolute transparency and maintain scientific credibility, the EQQN Research Center manages all active predictions, past predictions, and news reports through a secure Git-based workflow.

We do not use a traditional username/password portal. Instead, all data is stored securely in structured JSON files on our private GitHub repository.

How to Submit a Prediction

  1. Log in to your authorized GitHub account.
  2. Navigate to the private EQQN repository.
  3. Locate the relevant data file (e.g., data/active_predictions.json).
  4. Edit the file to include your new entry using the standard JSON format.
  5. Commit your changes and open a Pull Request.
  6. The Platform Administrator will review the Pull Request for scientific integrity and formatting. Once approved and merged, the live website will automatically update!

Note for Contributors: You must be granted explicit access to the EQQN private repository by the Administrator before you can submit Pull Requests. If you are a new researcher, please use the Contact page to request access.
